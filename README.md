# 🎮 Inventory & Crafting System — Java

This repository contains an academic project implementing a simple **inventory and crafting system** using the **Java programming language**. The project includes item management, crafting based on valid item combinations, and input validation during gameplay.

---

## 📌 Project Objectives

- To store and manage player items dynamically in an inventory
- To allow adding and removing items in real-time
- To implement crafting functionality using two item materials
- To provide user interaction through a console menu system

---


| File | Description |
|------|-------------|
| `urun.java` | Represents an item object (name, type, quantity) |
| `envantor.java` | Manages inventory using an ArrayList |
| `craftingSistemi.java` | Handles crafting logic between items |
| `ogeVeritabani.java` | Contains crafting recipe combinations |
| `Main.java` | Entry point with a console-based menu |
